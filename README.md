# Видеозвонок на WebRTC

Четыре файла, в отдельной папке проекта:

```
C:\scripts\webrtc-call\
    ├── .venv/          (свой, отдельный от остальных проектов)
    ├── server.py
    ├── index.html
    ├── requirements.txt
    └── README.md
```

- `server.py` — один процесс, который одновременно раздаёт страницу
  (`index.html`) и обрабатывает signaling для WebRTC (комнаты по коду,
  пересылка offer/answer/ICE между участниками). Само видео/аудио через
  сервер не идёт — только служебные данные для установки прямого
  соединения между браузерами.
- `index.html` — страница со звонком. Открывается в браузере, ничего
  устанавливать не нужно.
- `requirements.txt` — список зависимостей, нужен для локальной установки
  и для деплоя на Render.

## Локальный запуск (для теста на своём компьютере)

Один процесс, один порт — никаких отдельных `http.server` и туннелей на
два порта, как было раньше.

```powershell
cd C:\scripts\webrtc-call
.venv\Scripts\activate
pip install -r requirements.txt
python server.py
```

Откройте в браузере: `http://localhost:8765/index.html?room=test1`

Оставьте это окно терминала открытым — пока оно работает, звонок возможен
локально (в двух вкладках браузера на одном компьютере).

## Постоянная публичная ссылка через Render (рекомендуется)

Даёт постоянный адрес, не требует держать свой компьютер включённым для
сервера, не ломается от простоя (может только "засыпать" на бесплатном
тарифе после 15 минут без обращений — первое подключение после паузы
будет на 30-60 секунд медленнее, дальше работает нормально).

### Шаг 1. Выложить код на GitHub (без работы с git из терминала)

1. Зарегистрируйтесь на [github.com](https://github.com), если ещё нет
   аккаунта.
2. Нажмите "New repository" — создайте новый репозиторий, например
   `webrtc-call`. Можно публичный.
3. На странице репозитория нажмите "uploading an existing file" (или
   "Add file" → "Upload files") — и просто перетащите туда файлы
   `server.py`, `index.html`, `requirements.txt` (README тоже можно, но
   не обязательно). Никаких команд в терминале не требуется.
4. Нажмите "Commit changes" внизу.

### Шаг 2. Подключить репозиторий к Render

1. Зарегистрируйтесь на [render.com](https://render.com) (можно через
   аккаунт GitHub — это свяжет их автоматически).
2. В панели Render нажмите "New" → "Web Service".
3. Выберите ваш репозиторий `webrtc-call` из списка (или вставьте на него
   публичную ссылку).
4. В настройках укажите:
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python server.py`
   - **Instance Type**: Free
5. Нажмите "Create Web Service". Render соберёт и запустит проект — на
   это уйдёт пара минут, прогресс виден в логах на странице сервиса.

### Шаг 3. Получить постоянную ссылку

После успешного деплоя Render покажет адрес вида:

```
https://webrtc-call-xxxx.onrender.com
```

Ссылка для звонка — этот адрес плюс `/index.html?room=` и любой код
комнаты, например:

```
https://webrtc-call-xxxx.onrender.com/index.html?room=call1
```

Эта ссылка постоянная — можно сохранить в закладки и пользоваться ей
каждый раз, не пересобирая заново. Отправляйте её собеседнику как есть.

## Что дальше

- Сейчас сервер рассчитан ровно на 2 участников в комнате (P2P). Для
  группы из 3-4 человек потребуется расширение до mesh-схемы (несколько
  WebRTC-соединений на клиенте у каждого участника).
- При каждом новом изменении кода — просто загрузите обновлённые файлы в
  тот же репозиторий на GitHub (тем же способом через "Upload files"),
  Render подхватит изменения и передеплоит сервис автоматически.
